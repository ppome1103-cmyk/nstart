# 둘이섬 🏝️

둘이서만 노는 작은 섬. 각자 폰으로 접속해서 귀여운 캐릭터로 같이 돌아다니는 세로형 3D 웹게임이에요.

- **엔진:** Three.js + Vite
- **같이 접속:** PeerJS(WebRTC)로 폰끼리 직접 연결. 게임 서버가 따로 필요 없어요.

## 할 수 있는 것
- 귀여운 2등신 캐릭터 (이름과 색깔 선택)
- 작은 섬 돌아다니기: 집, 나무, 하트 꽃밭, 점프해서 올라가는 그루터기 계단
- 감정표현 👋 💖 😆, 말풍선 채팅
- 방 코드 4글자로 둘이 접속. 방 코드 배지를 누르면 초대 링크를 공유할 수 있어요.

## 조작
| 폰 | PC (테스트용) |
| --- | --- |
| 왼쪽 아래 조이스틱으로 이동 | WASD / 방향키 |
| 오른쪽 아래 ⬆️ 버튼으로 점프 | Space |
| 화면 드래그로 카메라 돌리기 | 마우스 드래그 |

## 실행
```bash
npm install
npm run dev      # 같은 와이파이의 폰에서 http://<PC IP>:5173 으로 접속
npm run build    # dist/ 에 배포용 파일 생성
```

## 배포 (GitHub Pages)
`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 빌드해서 배포해요.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 해요.

## 같이 접속하는 방법
1. 한 명이 **방 만들기** → 화면 위에 방 코드가 나와요.
2. 다른 한 명이 코드를 입력하고 **참가** (또는 공유받은 초대 링크로 바로 접속).

연결은 PeerJS 공개 서버로 처음에 서로를 찾은 다음, 폰끼리 직접 연결돼요.
일부 통신사나 회사 와이파이에서는 직접 연결이 막힐 수 있어요. 그럴 땐 둘 다 같은 와이파이에서 해보세요.

## 파일 구조
```
src/
  main.js      게임 루프, 로비, 물리, 카메라, 네트워크 메시지 처리
  avatar.js    치비 캐릭터 모델과 애니메이션
  world.js     섬, 바다, 나무, 집, 발판
  controls.js  조이스틱, 카메라 드래그, 키보드
  net.js       PeerJS 방 만들기, 참가, 재연결
```
