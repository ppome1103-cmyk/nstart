# 둘이랜드 🎡

둘이서만 노는 놀이공원. 각자 폰으로 접속해서 귀여운 캐릭터로 같이 놀이기구를 타는 세로형 3D 웹게임이에요.

- **엔진:** Three.js + Vite
- **같이 접속:** PeerJS(WebRTC)로 폰끼리 직접 연결. 게임 서버가 따로 필요 없어요.
- **소리:** 파일 없이 Web Audio로 직접 만들어요 (오르골 음악, 비명, 물보라, 범퍼 소리...).

## 놀이기구 (11개)
| 기구 | 특징 |
| --- | --- |
| 🎢 별똥별 코스터 | 24m 리프트 언덕, 급낙하, 루프, 나선, 에어타임 언덕. 실제 물리(중력/마찰)로 미리 계산해서 커브마다 기울어져요 |
| 🎡 구름 관람차 | 계속 천천히 돌아요. 둘이 같은 칸에 타면 꼭대기에서 하트 |
| 🎠 별빛 회전목마 | 말과 유니콘이 위아래로, 오르골 음악이 크게 |
| 🗼 하늘 낙하 | 34m까지 올라가서 언제 떨어질지 모르게 기다렸다가 자유낙하 |
| 🏴‍☠️ 하트 해적선 | 점점 크게 흔들려서 77도까지 |
| 🪁 구름 회전그네 | 빨리 돌수록 의자가 바깥으로 날아가요 |
| ☕ 빙글빙글 커피컵 | 버튼을 연타하면 더 빨리. 너무 돌리면 내려서 어질어질 |
| 🚗 통통 범퍼카 | 직접 운전! 서로 박으면 통~ (진동) |
| 🌊 퐁당 통나무 | 물길 따라 가다가 큰 낙하 → 물보라, 화면에 물방울 |
| 👻 두근두근 유령의 집 | 깜깜한 집 안을 손전등 수레로. 유령, 박쥐, 눈이 따라오는 액자 |
| 🚂 꼬마 기차 | 공원을 한 바퀴 도는 교통수단. 역 4곳에서 타고 내려요 |

## 그 밖에
- **같이 타기:** 상대가 탄 기구 앞에 가면 "💕 같이 타기" 버튼. 옆자리에 앉고 두 폰에서 똑같이 움직여요.
- **실감 연출:** 속도에 따라 시야가 넓어지고 속도선, 바람 소리, 화면 흔들림, 진동(안드로이드), 자동 비명/만세.
- **1인칭/3인칭:** 탑승 중 🎥 버튼으로 시점 전환, 화면을 드래그해서 둘러보기.
- **라이드 포토:** 무서운 순간에 자동으로 사진이 찍혀서 🖼️ 앨범에 저장. 📸 버튼으로 둘이 셀카.
- **게임 부스:** 🎈 풍선 다트, 🔨 두더지 콩콩 → 🎟️ 티켓 → 🎁 선물 가게에서 왕관, 리본, 토끼 머리띠, 하트 풍선, 곰인형...
- **간식 수레:** 아이스크림, 솜사탕, 츄러스를 받아서 들고 다니기.
- **밤 모드:** 🌙 버튼으로 밤이 되면 전구가 켜지고 불꽃놀이 (두 폰이 같이 바뀌어요).
- **지도:** 🗺️ 버튼으로 놀이기구까지 바로 이동, 상대 옆으로 이동.

## 조작
| 폰 | PC (테스트용) |
| --- | --- |
| 왼쪽 아래 조이스틱으로 이동 | WASD / 방향키 |
| 오른쪽 아래 ⬆️ 버튼으로 점프 | Space |
| 화면 드래그로 카메라 돌리기, 두 손가락으로 확대/축소 | 마우스 드래그, 휠 |
| 가운데 아래 버튼으로 타기/앉기/받기 | 클릭 |

## 실행
```bash
npm install
npm run dev      # 같은 와이파이의 폰에서 http://<PC IP>:5173 으로 접속
npm run build    # dist/ 에 배포용 파일 생성
```
`main` 브랜치에 푸시하면 GitHub Pages로 자동 배포돼요: https://ppome1103-cmyk.github.io/nstart/

## 파일 구조
```
src/
  main.js           게임 루프, 로비, 이동/충돌, 카메라, 네트워크, 지도/가방/사진
  avatar.js         치비 캐릭터, 포즈, 꾸미기 아이템
  controls.js       조이스틱, 드래그, 탭, 키보드
  net.js            PeerJS 방 만들기/참가/재연결
  audio.js          효과음과 오르골 음악 (Web Audio)
  fx.js             속도선, 물방울, 어둠, 화면 흔들림
  core/             재질, 메시 합치기, 레일 곡선(Track) + 주행 시뮬레이션, 시계 동기화
  park/             놀이공원 맵, 배치도, 불꽃놀이
  rides/            놀이기구 11개 + 공통 틀(Ride) + 관리자(RideManager)
  games/booths.js   풍선 다트, 두더지, 선물 가게
  ui/hud.js         화면 버튼과 창
```

## 두 폰이 똑같이 움직이는 원리
방장 폰의 시계를 기준으로 "놀이공원 시간"을 맞춰요. 놀이기구는 누가 탔을 때 출발 시각만 서로 알려주고, 그 뒤 움직임은 미리 계산해둔 시간표대로 각자 폰에서 그려요. 그래서 데이터를 거의 주고받지 않아도 같은 순간 같은 위치에 있어요.
